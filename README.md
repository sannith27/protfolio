# Portfolio — Software Developer

A modern, responsive personal portfolio built with **React + Vite**.

## Getting Started

1. Install [Node.js](https://nodejs.org) (v18+).
2. Open a terminal in this folder.
3. Install dependencies:

   ```
   npm install
   ```

4. Start the dev server:

   ```
   npm run dev
   ```

5. Open the URL shown (default `http://localhost:5173`).

## Customize

Edit **`src/data.js`** to update your:

- Name, role, tagline, contact info, and social links
- Skills, projects, work experience, education, certifications

Then adjust colors/theme in **`src/index.css`** (CSS variables at the top).

## Build for production

```
npm run build
npm run preview
```

The build output goes to the `dist/` folder, which you can host on services like Netlify, Vercel, or GitHub Pages.
